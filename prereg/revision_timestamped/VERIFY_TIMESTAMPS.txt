How to verify the timestamps of these files

Each file X has a proof X.ots made with OpenTimestamps (https://opentimestamps.org) on 22 October 2026. The proof
commits the SHA-256 hash of X to the Bitcoin blockchain; it shows that X existed in exactly this form no later than
the time of the block, and that it has not changed since. It does not show when the text was first written; the dated
md5 log (prereg_md5_log.txt) records that, as kept by the authors.

Verify in a browser: open https://opentimestamps.org, drop the .ots file and then the original file onto the page.
Verify on the command line:  pip install opentimestamps-client;  ots verify PREREG_revision.md.ots
